# Development workflow

Follow stages 0–12 in [PROJECT_REQUIREMENTS.md](../requirements/PROJECT_REQUIREMENTS.md).

1. Agree the stage goal.
2. List files to change.
3. Implement only that stage.
4. Verify with the checklist for the stage.
5. Open a PR into `production` when ready.

Teammates stay on assigned feature branches and respect API/data/UI contracts under `docs/`.
