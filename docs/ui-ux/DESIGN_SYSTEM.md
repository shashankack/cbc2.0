# Design system

- Use Material UI (MUI) as the default component system.
- Put shared theme configuration in `frontend/theme/`.
- Put reusable UI primitives in `frontend/components/`.
- Put domain-specific components in `frontend/features/<feature>/components/`.
- Do not add Tailwind CSS.
- Support loading, empty, error, and success states.
- Use accessible labels, keyboard-friendly controls, and responsive layouts.
- Never label straight-line (Haversine) distance as walking distance.
